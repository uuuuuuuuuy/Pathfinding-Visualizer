# 第6章 界面设计与交互实现

## 6.1 字体与本地化支持
为了满足中文显示需求，系统在 `assets/fonts` 目录中自动扫描可用字体，通过 `src/fonts.py` 与 `src/constants.py` 的加载逻辑优先选择包含中文字符的 TTF/OTF 文件，并在缺失粗体时自动回退。所有控件均复用该字体配置，保证界面一致性。

## 6.2 工具栏与菜单布局
`src/ui/layout.py` 中定义了顶部工具栏与下拉菜单。算法、速度、比较模式与迷宫生成等选项采用下拉按钮实现，选择结果展示在摘要行中，旁边同步显示当前状态文本。全局控制按钮（开始、暂停、重置）位于右侧，以醒目的颜色区分。

## 6.3 图例与提示
图例区分为“节点类型”和“搜索状态”两组，分别展示迷宫墙体、障碍、权重节点、起点、终点、访问节点及最短路径节点。权重提示使用小字号展示数字键映射，指导用户快速放置不同权重。图例高度经过多次迭代优化，确保不遮挡迷宫网格。

## 6.4 状态显示机制
`set_status` 函数集中维护状态文本，并在摘要行中更新显示。状态栏采用浅色背景与紧凑布局，避免文字溢出或残影。动画与算法执行过程中，会在关键步骤触发状态更新，如“迷宫生成中”“算法运行完成”“未找到路径”等。

## 6.5 动画控制与事件处理
动画模块支持暂停、恢复与清空队列，按钮事件通过 `src/widgets.py` 的回调机制触发。主循环在每帧检测 PyGame 事件，处理鼠标拖拽放置节点、键盘快捷键（数字键设置权重、空格开始动画等）与窗口关闭事件，保证交互顺畅。

## 6.6 响应式布局考虑
虽然 PyGame 非传统意义上的响应式框架，系统仍通过常量管理工具栏、摘要行与图例的高度，在窗口缩放或分辨率调整时能够保持比例适配。控件位置每帧重算，避免因状态变化导致按钮重叠。

## 6.7 本章小结
本章介绍了系统的界面设计思想与实现细节，强调了中文显示、控件布局、状态提示与动画控制之间的协同关系。
