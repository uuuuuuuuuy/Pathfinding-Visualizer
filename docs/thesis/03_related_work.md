# 第3章 相关研究

## 3.1 图搜索算法研究现状
图搜索算法是人工智能与运筹学的重要研究方向。经典算法如广度优先搜索（BFS）和深度优先搜索（DFS）在无权图中表现突出，Dijkstra 算法在带权图中提供最短路径保证，而 A* 算法通过引入启发函数在效率与最优性之间取得平衡。近年来，双向搜索、启发式优化以及基于机器学习的搜索策略成为研究热点，但其核心仍离不开对状态空间的有效探索。

## 3.2 可视化教学工具
算法可视化工具有助于降低学习门槛。国外如 VisuAlgo、Pathfinding.js 等项目提供在线演示，但往往缺乏中文化界面、离线运行能力或自定义迷宫功能。国内相关工具大多聚焦于单一算法或缺乏动画细节。《Pathfinding Visualizer》项目通过 PyGame 提供跨平台桌面体验，支持算法切换、速度调节与权重节点展示，兼顾教学与实验需求。

## 3.3 交互式系统设计趋势
现代教学工具强调交互性与反馈机制。通过实时状态展示、快捷键提示与动画暂停功能，用户能够在观察过程中进行干预，进一步理解算法行为。系统的字体自适应、菜单布局与状态提示等设计充分考虑中文用户体验，体现了以用户为中心的界面设计趋势。

## 3.4 本章小结
本章梳理了路径规划算法与可视化工具的研究现状，指出了中文化交互式系统在教学领域的需求，为后续章节中对系统设计与实现的详细讨论奠定基础。
