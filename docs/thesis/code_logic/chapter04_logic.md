# 第4章配套代码逻辑说明

本说明对论文第4章“设计实现”中引用的关键程序流程进行抽象化描述，帮助撰写正文时准确描述算法与界面实现的工作机制。

## 1. 算法注册与调度
- **算法元信息**：`src/menu_config.py` 中的 `ALGORITHMS` 列表保存若干 `AlgorithmDefinition`，每项包含算法名称、简介、可适用的节点权重类型以及执行函数指针。论文第4章各小节即对应这些条目。
- **执行入口**：主循环根据当前选定的 `AlgorithmDefinition.executor` 调用算法函数，并传入网格、起终点、动画记录器等上下文对象，确保所有算法共享一致的输入与输出接口。

## 2. 搜索算法实现要点
- **BFS/DFS**：`src/maze.py` 中实现无权搜索逻辑。BFS 使用队列结构逐层展开；DFS 通过栈结构进行深度探索。两者在访问节点时会调用动画记录器记录“访问”“回溯”等事件，供动画模块播放。
- **Dijkstra 与 A***：在 `src/maze.py` 中，使用最小堆维护待处理节点，松弛时更新距离表与前驱表。A* 在此基础上增加启发式估价函数（默认曼哈顿距离）。两种算法均会把节点的当前代价写入动画序列，支持权重节点的高亮展示。
- **双向搜索**：双向 BFS/Dijkstra 通过两个前沿同时推进，并在检测到节点交汇时合并路径。相关逻辑在 `src/maze.py` 中封装为辅助函数，保障对称性与终止条件的正确处理。

## 3. 迷宫生成策略
- **策略定义**：`src/menu_config.py` 中的 `MAZE_GENERATORS` 与 `MazeGeneratorDefinition` 描述递归分割、随机深度优先、普里姆等算法的名称与入口函数。
- **执行流程**：`src/main.py` 根据用户选择调用相应生成器，生成器在 `src/maze.py` 中逐步修改网格节点类型，并通过动画记录器产生日志，以便在界面上呈现墙体构建过程。

## 4. 动画记录与播放
- **记录结构**：`src/animations.py` 定义 `AnimationQueue`，内部维护访问队列、最短路径回溯以及当前帧索引。算法在执行期间将节点状态变化写入该队列。
- **播放控制**：动画模块提供 `animate_nodes`、`pause`、`resume`、`clear` 等方法，与全局按钮的回调关联。帧播放时按动画速度读取队列内容，并更新节点的颜色与状态标记，驱动网格重绘。

## 5. 界面响应与状态更新
- **状态文本**：`src/main.py` 中的 `set_status` 函数集中维护状态字符串，在迷宫生成、算法执行、动画结束等事件点更新。摘要行中的“状态”标签读取该值，实现论文所述的实时提示。
- **摘要行同步**：同一文件内的 `update_summary_labels` 根据全局状态刷新“当前算法”“当前速度”“当前比较模式”“当前迷宫”四项文本，保证界面与内部选择一致。

## 6. 字体与本地化
- **字体解析**：`src/fonts.py` 的 `resolve_font_pair` 扫描 `assets/fonts/` 目录，优先选择包含中文字符的 TTF/OTF 文件，并在缺少粗体时复用常规体。`load_font` 提供统一接口供控件加载。
- **常量配置**：`src/constants.py` 设定工具栏高度、字号、颜色与间距，供布局模块与绘制函数调用，使论文中描述的配色与结构得以固化实现。

## 7. 控件交互与事件驱动
- **按钮与下拉菜单**：`src/widgets.py` 中的控件类管理鼠标悬停、高亮、展开与点击事件。下拉菜单在选择项时调用绑定回调更新全局状态，并自动收起列表。
- **暂停与重置**：`src/main.py` 的 `handle_pause`、`handle_reset` 函数对接动画模块与迷宫网格，确保暂停时冻结帧推进，重置时清空动画并恢复默认节点状态，满足论文中“可暂停、可重新开始”的描述。

## 8. 图例与提示绘制
- **图例构建**：`src/ui/layout.py` 通过 `build_legend` 生成“节点类型”“搜索状态”两组控件，调用 `LegendItem`（定义于 `src/widgets.py`）绘制示例色块与文字。
- **权重提示**：同一模块在图例下方绘制数字键提示，引用 `src/constants.py` 中的字号与颜色定义，使用户了解如何投放不同权重节点。

## 9. 章节对应关系
论文第4章的每个小节均可映射到上述模块：
- 4.2-4.6 涉及的算法逻辑由 `src/maze.py` 与动画模块协同完成；
- 4.7 与 4.8 描述的迷宫生成与扩展接口来自 `menu_config.py` 与对应生成器函数；
- 4.9 的界面实现细节覆盖 `ui/layout.py`、`widgets.py`、`fonts.py`、`constants.py`；
- 4.10 的总结强调的正是这些模块之间的数据驱动协同关系。
