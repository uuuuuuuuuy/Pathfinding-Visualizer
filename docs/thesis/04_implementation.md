# 第4章 设计实现

## 4.1 算法库概览
系统在 `src/menu_config.py` 中以数据结构的形式定义算法元信息，包括名称、中文描述、适用权重类型与可视化配色。目前覆盖广度优先搜索（BFS）、深度优先搜索（DFS）、Dijkstra、A*、双向 BFS、双向 Dijkstra 等经典策略，既支持无权图最短步数求解，也兼顾带权图与启发式搜索。

## 4.2 广度优先搜索（BFS）
BFS 适用于无权图场景，能够以最少步数找到路径。系统使用队列维护待访问节点，`src/animations.py` 记录节点出队、访问与回溯的动画帧。节点访问时会被染成蓝色，最终路径以黄色呈现，帮助学习者识别搜索前沿的扩散形态。

## 4.3 深度优先搜索（DFS）
DFS 通过栈结构实现深度探索，虽然不保证最短路径，但能展示回溯与分支遍历过程。系统采用迭代写法避免递归栈溢出，同时在状态栏提醒用户其适用场景，使动画更加贴合算法特点。

## 4.4 Dijkstra 算法
Dijkstra 算法在非负权重的条件下提供全局最优路径。实现中使用优先队列维护最短距离候选节点，并在节点松弛时将更新动作写入动画队列。权重节点以不同色阶展示，用户可通过数字键 2-9 设置权值，观察成本累积对路径选择的影响。

## 4.5 A* 搜索
A* 在 Dijkstra 基础上引入启发式估价函数，系统默认采用曼哈顿距离以适配网格环境。动画显示搜索前沿更集中于目标方向，状态栏提示启发式的收敛优势，有助于对比不同策略的效率。

## 4.6 双向搜索
双向 BFS 与双向 Dijkstra 同时从起点与终点展开搜索，在 `src/maze.py` 中实现节点会合检测。当两侧搜索相遇时合并路径并触发状态提示，让用户直观看到双向搜索在缩短探索范围方面的优势。

## 4.7 迷宫生成策略
系统内置递归分割、随机深度优先、普里姆等迷宫生成算法。根据用户选择在 `src/main.py` 中调用对应生成器，并通过动画模块逐步绘制墙体。生成过程中支持暂停、恢复与重置，确保实验可重复与可控。

## 4.8 算法扩展接口
借助 `AlgorithmDefinition` 数据结构，开发者可以在不修改 UI 逻辑的前提下新增算法。只需提供名称、描述、执行函数和适配条件，系统便会自动在菜单中展示新选项，体现了数据驱动的扩展性。

## 4.9 界面与交互实现
### 4.9.1 字体与本地化支持
`assets/fonts` 目录中可放置任意中文字体文件，`src/fonts.py` 与 `src/constants.py` 会自动扫描可用的 TTF/OTF 文件，优先选择包含 CJK 字形的资源，并在缺少粗体版本时实现回退。全局控件统一加载该字体，保证界面中文字符渲染正常。

### 4.9.2 工具栏与菜单布局
顶部工具栏由 `src/ui/layout.py` 构建，左侧排列算法、速度、比较模式与迷宫生成等下拉菜单，右侧集中放置“开始可视化”“暂停动画”“重新开始”等全局控制按钮。摘要行展示当前选择与状态文本，控件尺寸随窗口大小自适应调整。

### 4.9.3 图例与提示
图例区域划分为“节点类型”和“搜索状态”两组，分别展示迷宫墙体、障碍、权重节点以及起点、终点、访问节点、最短路径节点的样式。权重提示采用小字号列出数字键与权值的映射，指导用户快速布置测试场景。

### 4.9.4 状态显示机制
`set_status` 函数集中管理状态文本并写入摘要行，保证提示与选择信息并列展示。迷宫生成、算法运行及动画结束等关键时刻都会触发状态更新，避免出现文本重影或截断。

### 4.9.5 动画控制与事件处理
动画模块支持暂停、恢复与清空操作，按钮事件通过 `src/widgets.py` 的回调机制触发。主循环在每帧处理 PyGame 事件，响应鼠标拖拽放置节点、键盘快捷键（数字键设置权重、空格启动算法等）以及窗口关闭请求，确保交互流畅。

## 4.10 本章小结
本章围绕算法实现与界面交互两个层面展开，阐述了系统在数据驱动的算法管理、迷宫生成、字体本地化、工具栏布局、状态提示与动画控制等方面的关键实现，为实验评估与后续优化提供技术支撑。
