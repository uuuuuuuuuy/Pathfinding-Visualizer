# 第7章 实验设计与评估

## 7.1 实验目标
实验旨在评估不同算法在相同迷宫配置下的性能差异，以及界面交互对学习效率的提升。重点考察路径长度、访问节点数量、执行时间与用户操作体验。

## 7.2 实验环境
- 操作系统：Windows 11 / Ubuntu 22.04
- Python 版本：3.10 及以上
- 依赖库：Pygame 2.6.1
- 硬件配置：8GB 内存及以上，保证动画流畅

## 7.3 评估指标
1. **访问节点数**：反映算法在状态空间中的探索范围；
2. **最短路径长度**：验证算法结果的最优性；
3. **动画时长**：结合速度设置衡量用户等待时间；
4. **交互操作次数**：统计用户放置节点、切换算法的次数，用于分析学习曲线。

## 7.4 实验流程
1. 选择固定的迷宫结构与起终点配置，分别执行各算法；
2. 调整速度设置，记录动画时长与节点访问顺序；
3. 通过比较模式同时运行多个算法，观察结果差异；
4. 利用暂停与重置功能，在关键节点进行截图与分析；
5. 收集用户反馈，评估界面布局与交互提示的有效性。

## 7.5 案例分析
- **复杂迷宫场景**：递归分割迷宫配合权重节点，可观察 Dijkstra 与 A* 在带权图中的表现差异；
- **稀疏障碍场景**：对比 BFS 与双向 BFS 在开放空间中的速度；
- **高权重区域**：通过数字键设置 5-9 的权重，验证算法对成本累积的处理能力。

## 7.6 数据记录与可视化
实验数据可导出为 CSV 或截图方式保存，利用第三方工具进行统计分析。结合状态栏文本，可构建时间轴描述算法执行阶段。

## 7.7 本章小结
通过规范的实验流程与评估指标，系统能够为算法教学与论文撰写提供量化依据，为下一章的总结与展望提供数据支撑。
