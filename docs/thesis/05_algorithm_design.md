# 第5章 算法设计与实现

## 5.1 算法库概览
系统在 `src/menu_config.py` 中定义了算法元信息，包括名称、描述、适用节点权重与可视化颜色。主要覆盖 BFS、DFS、Dijkstra、A*、双向 BFS、双向 Dijkstra 等经典算法，满足无权图与带权图的需求。

## 5.2 广度优先搜索（BFS）
BFS 适用于无权图，能够在最短步数内找到路径。系统将待访问节点存入队列，并在 `src/animations.py` 中按访问顺序记录动画帧。节点被访问时染为蓝色，最终路径以黄色回溯呈现。

## 5.3 深度优先搜索（DFS）
DFS 通过栈或递归实现深度探索。由于 DFS 不保证最短路径，系统在状态栏提示其适用场景，同时通过动画展示回溯过程，帮助用户理解其盲目性。实现中采用栈结构避免递归栈溢出。

## 5.4 Dijkstra 算法
Dijkstra 算法在权重非负的情形下保证全局最优路径。系统利用优先队列维护当前最小距离节点，并在节点松弛时更新动画队列。权重节点通过颜色深浅区分，用户可借助数字键设置不同权值。

## 5.5 A* 搜索
A* 在 Dijkstra 的基础上引入启发式估价函数。系统采用曼哈顿距离作为默认启发式，以适配栅格环境。动画中可观察到搜索前沿更集中于目标方向，提升用户对启发式作用的认知。

## 5.6 双向搜索
双向 BFS 与双向 Dijkstra 同时从起点与终点展开搜索，在 `src/maze.py` 中实现节点会合检测。当两侧搜索交汇时，系统合并路径并触发状态栏提示，用以展示双向搜索的效率优势。

## 5.7 迷宫生成算法
系统包含递归分割、随机深度优先、普里姆等迷宫生成策略。在 `src/main.py` 中，根据用户选择调用对应生成器，并通过动画模块逐步绘制墙体。生成过程中可暂停或重置，保持交互灵活性。

## 5.8 算法扩展接口
通过 `AlgorithmDefinition` 数据结构，可便捷添加新算法。开发者仅需定义名称、描述、执行函数与适配条件，UI 会自动呈现新选项。这种解耦设计降低了后续扩展成本。

## 5.9 本章小结
本章对系统实现的主要算法进行了逐一解析，并说明了可视化过程中的动画与状态反馈机制。用户可借此理解各算法的特性与实现细节。
